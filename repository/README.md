# Kun Zhu — academic website

Responsive, dependency-free academic website for Kun Zhu, PhD candidate at Tsinghua University.

## Preview locally

Open `index.html`, or run:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Visit http://127.0.0.1:8765. No build step or package installation is required.

## Files

- `index.html`: biography, research interests, wet lab skills, publications, talks, honors, and contact details.
- `styles.css`: ivory and green theme with responsive layouts.
- `assets/kun-zhu.jpg`: portrait, displayed without color filters.
- `assets/tsinghua-logo.png`: full university signature supplied by the owner.
- `.nojekyll`: enables direct static-file serving on GitHub Pages.

The CV PDF is intentionally excluded from the website. All asset paths are relative, supporting GitHub Pages project paths.

## Hosting

To enable GitHub Pages, select the main branch and root directory in the repository's Pages settings. The expected project URL is https://harry20230228.github.io/Kun_Zhu.github.io/; verify the published URL in Pages settings.

## Content

Profile and publication details were supplied by the owner. Footer credit and a non-tracking source marker reflect the intake preferences. No details have been submitted to a third-party directory. The site has no analytics or external font dependencies.
